# Rules

- Always create a new branch for each requested change.
- Once the changes are in the branch, create a new pull request for review.
- Always display the pull request address as the last thought of the chat.
- Be less verbose in your output; just summarize what you did.

# Project notes

- Static PWA at repo root (no build step). Serve with any static server.
- Bump `VERSION` in `sw.js` on every release so users get the update prompt.
